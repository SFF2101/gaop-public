Governed AI Operations Platform (GAOP)

Governed AI Operations Platform (GAOP) is a private, non-commercial orchestration component used within the Home Assistant Architecture & Optimisation project.

GAOP supports governed transaction handling, archive and provenance storage, and project evidence management.

Google Drive access

GAOP uses Google Drive through the limited drive.file OAuth scope. This allows the application to access files that it creates or files explicitly made available to it. GAOP does not request unrestricted access to the user's Google Drive.

Google Drive is used as GAOP's archive and provenance plane. It is not used as the live transaction repository.

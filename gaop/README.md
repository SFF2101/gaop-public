# Governed AI Operations Platform (GAOP)

Durable, repository-installed GAOP generation (v0.8.x dual-AI production build): a Dashboard-authorised, fail-closed transaction
control plane for Home Assistant. One Authorize press on the GAOP panel is the complete owner approval
for a bounded transaction; executors (Claude/ChatGPT/GitHub routes) can propose, claim and return results
but can never create authority. v0.8.x runs **synthetic operations only**; Claude executes, ChatGPT designs/reviews.

See **DOCS.md** for the operating model and **CHANGELOG.md** for history.

GAOP Privacy Policy

Last updated: 4 October 2026

Governed AI Operations Platform (GAOP) is a private, non-commercial application operated for the Home Assistant Architecture & Optimisation project.

Google user data accessed

GAOP requests only the Google Drive drive.file OAuth scope. This permits access to files created by the application and files explicitly made available to it. GAOP does not request unrestricted access to Google Drive.

How Google user data is used

Google Drive is used only for GAOP archive, provenance, and governed project evidence storage.

Storage and security

OAuth credentials are retained in private application runtime storage. Credentials and runtime secrets are not stored in public source-control repositories, public documentation, or public project evidence.

Sharing

Google user data is not sold, used for advertising, or shared with advertisers or unrelated third parties.

Revocation

The Google account owner can revoke GAOP's OAuth authorization through Google Account security settings.

Contact

Contact details are provided through the OAuth consent screen support address.
